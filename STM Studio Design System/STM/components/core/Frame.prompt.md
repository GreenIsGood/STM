Media well with red corner brackets. STM's signature empty-state: it names the missing asset instead of faking it.

```jsx
<Frame height={620} label="Showreel — 16:9" note="supply MP4 or Vimeo / YouTube link" badge="REEL 2026" />
<Frame height={240} src="assets/photos/studio-cyclorama.jpg" alt="Skylight cyclorama" />
```

Never put a stock photo or a gradient in a Frame you don't have the asset for — write the brief in `note` and let it stay empty. Real imagery drops the brackets entirely.
