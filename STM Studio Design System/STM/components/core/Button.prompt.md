Square-cornered CTA. Primary is always the WhatsApp action; outline is always secondary.

```jsx
<Button variant="primary" size="md" icon="whatsapp">Start a project on WhatsApp</Button>
<Button variant="outline" size="md" iconAfter="arrowRight">See the work</Button>
```

Never round the corners and never use more than one primary per viewport. On mobile both buttons go `fullWidth` and stack with an 11px gap.
