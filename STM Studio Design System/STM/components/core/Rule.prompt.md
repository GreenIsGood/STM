1px hairline — STM's only divider. There are no shadows or cards in this system; rules and ground-colour shifts do all the separating.

```jsx
<Rule weight="rule" />
<Tick width={34} />
```

Five opacity steps map to five jobs: `cell` inside grids, `inset` around placeholders, `rule` between service rows, `strong` for hero measure lines, `control` for outline buttons. `Tick` is the 2px accent stub above unit column headings.
