A service as a ruled ledger row: red number, fixed 420px title column, flowing description.

```jsx
<Rule />
<ServiceRow number="01" title="TV commercials & brand films">
  Concept to delivered master. We assemble and run the full unit…
</ServiceRow>
<Rule />
```

Wrap the stack in `<Rule />` above and below every row — the rules, not spacing, do the separating.
