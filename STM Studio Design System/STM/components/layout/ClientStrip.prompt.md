Divided grid of client wordmarks, hairline-ruled top and bottom.

```jsx
<ClientStrip clients={['KION','LeadsMart','El Wady','Avanti','Watson Says','Vaseline','Egypt Int’l Airshow']}
  note="[ set as wordmarks — replace with client logo files when cleared ]" />
```

Names longer than 12 characters drop to 15px automatically. Keep the bracketed note until real logo files are cleared.
